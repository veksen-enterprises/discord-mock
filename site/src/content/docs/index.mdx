A fake Discord that a stock discord.js `Client` logs in to, so a test runs the bot as it ships. It runs a real HTTP server (REST) and WebSocket server (Gateway) on `127.0.0.1`, keeps an in-memory model of guilds, channels, members, messages and interactions, and refuses what Discord refuses.

Nothing in discord.js is mocked. No `vi.mock("discord.js")`, no hand-built interactions, no spies on `interaction.reply`. A test builds a World, starts the bot, acts as members and reads what they would see.

## Install

```sh
npm install --save-dev discordjs-test-kit
```

Peers: `discord.js` `^14.26.4` and `vitest` `^4.1.2 || ^5.0.0`. Node 22 or 24.
